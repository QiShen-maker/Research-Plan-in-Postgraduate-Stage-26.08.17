# 复杂工况下可信故障诊断文献库

本仓库围绕“事前数据可信化—事中故障识别—扩展状态更新”组织文献、笔记、数据集信息与复现材料。

## 研究主线

1. **事前：传感器与观测数据校准**——提高输入数据的准确性、一致性与可用性。
2. **事中：故障识别**——通过深度学习、小样本学习、不平衡学习和物理规律完成故障检测、分类与可信决策。
3. **扩展：跨域协同与持续更新**——通过联邦学习、迁移学习、领域适应和持续学习更新模型状态。

## 目录

- `00_研究总览与索引`：研究问题、分类规则和文献索引说明。
- `01_事前_传感器与观测数据校准`：标定、漂移补偿、去噪、误差校正与观测质量。
- `02_事中_故障识别`：深度学习、小样本、不平衡、物理—数据协同和可信解释。
- `03_扩展_跨域协同与持续更新`：联邦、迁移、领域适应、持续学习与在线更新。
- `90_通用资源`：数据集、评价指标、代码与复现资料。
- `99_待分类`：暂时无法确定主要贡献方向的新材料。

## 归档规则

1. 一篇文献只存放在“主要贡献”对应的一个目录中，交叉主题通过文献笔记中的标签记录。
2. 建议文件名采用 `年份_第一作者_简短标题`，论文与笔记保持同名。
3. 新材料先进入 `99_待分类`，阅读后再移动到正式方向。
4. 优先保存文献笔记、DOI、网页链接和可合法分发的材料；大型数据与受版权保护的全文不直接上传公共仓库。
