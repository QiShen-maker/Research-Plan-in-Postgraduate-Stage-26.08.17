# 研究总览与索引

## 总体问题

面向变转速、变负载、强噪声、跨设备与标签稀缺等复杂工况，研究从观测数据校准、故障识别到模型持续更新的完整技术链。

## 推荐总题目

**复杂工况下物理—数据协同驱动的滚动轴承小样本可信故障诊断方法研究**

## 建议标签

- 对象：轴承、齿轮箱、旋转机械、工业设备。
- 工况：变转速、变负载、强噪声、跨设备、传感器漂移。
- 任务：异常检测、故障分类、开放集识别、状态评估、寿命预测。
- 方法：深度学习、小样本、类别不平衡、PINN、Koopman、FNO、液态神经网络。
- 可信性：鲁棒性、不确定性校准、域外检测、可解释性。

多主题文献按主要创新点归档，并在笔记中补充其他标签，避免重复保存。
